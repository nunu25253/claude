# 03. 画面一覧

本ドキュメントは本システムのダッシュボード画面を中心とした画面一覧です。画面IDは `SCR-XXX` の形式で採番します。画面遷移の詳細は `04_screen_flow.md` を参照してください。

## 画面一覧表

| 画面ID | 画面名 | 概要 | 主要コンポーネント |
|--------|--------|------|---------------------|
| SCR-001 | ログイン画面 | メールアドレス・パスワードでログインする。 | ログインフォーム、パスワードリセットリンク、新規登録リンク |
| SCR-002 | 新規登録画面 | 新規ユーザーアカウントを作成する。 | 登録フォーム、利用規約同意チェックボックス |
| SCR-003 | ホーム画面 | ログイン後の起点となるダッシュボード。直近のトレンド・保存済み分析・急上昇投稿のサマリーを表示する。 | サマリーカード群（急上昇投稿、週間ハイライト）、クイック検索バー、最近の保存済み分析リスト、通知パネル |
| SCR-004 | トレンド画面 | プラットフォーム・ジャンル横断のトレンドを可視化する。 | プラットフォーム/ジャンルフィルタ、トレンド推移グラフ、トレンド投稿カードグリッド |
| SCR-005 | 競合分析画面（一覧） | 登録した競合アカウントの一覧と主要統計を表示する。 | 競合アカウント登録フォーム、競合アカウント一覧テーブル（平均いいね/平均コメント/投稿頻度）、比較選択チェックボックス |
| SCR-006 | 競合分析画面（詳細） | 個別競合アカウントの詳細統計・投稿ランキング・投稿時間帯傾向を表示する。 | アカウントプロフィールカード、統計サマリー（平均動画時間・平均文字数等）、伸びる投稿ランキングテーブル、投稿時間帯ヒートマップ、ジャンル分布チャート |
| SCR-007 | 投稿分析画面（検索・URL入力） | 投稿URLを入力する、またはキーワード/ハッシュタグ/アカウントで検索して分析対象を選ぶ。 | URL入力フォーム、検索タブ（キーワード/ハッシュタグ/アカウント）、検索結果一覧、分析履歴リスト |
| SCR-008 | 投稿分析結果詳細画面 | AI分析結果・BuzzScore・改善案・類似投稿を表示する。 | 投稿プレビューカード、BuzzScoreゲージ（内訳表示）、AI分析タブ（バズ理由/ターゲット層/フック/CTA/感情/構成/文章/投稿時間/ハッシュタグ）、改善提案リスト、類似投稿カルーセル、保存ボタン、レポート出力ボタン |
| SCR-009 | AIレポート一覧画面 | 生成済みレポートの一覧を表示する。 | レポート一覧テーブル（形式/生成日時/ステータス）、再ダウンロードボタン、新規生成ボタン |
| SCR-010 | AIレポート生成・詳細画面 | レポートの生成設定（形式選択）と、生成後のプレビュー・ダウンロードを行う。 | 形式選択（PDF/Markdown/HTML）、生成進捗インジケーター、レポートプレビュー、ダウンロード/共有ボタン |
| SCR-011 | ランキング画面 | 急上昇/週間/月間/ジャンル別/SNS別のランキングを表示する。 | ランキング種別タブ、プラットフォーム/ジャンルフィルタ、ランキングテーブル（順位/投稿サムネイル/BuzzScore/主要数値）、投稿詳細への導線 |
| SCR-012 | 保存済み分析画面 | ユーザーが保存した分析結果を一覧管理する。 | フォルダツリー、保存済み分析カード一覧、メモ編集、削除・フォルダ移動操作 |
| SCR-013 | 設定画面 | 通知設定・デフォルトプラットフォーム・言語/タイムゾーン・（管理者は）API連携設定を行う。 | プロフィール編集フォーム、通知設定トグル、言語/タイムゾーン選択、APIキー管理セクション（管理者のみ表示） |
| SCR-014 | 検索結果画面 | キーワード/ハッシュタグ/アカウント検索の結果を統合表示する。 | 検索条件バー、絞り込みフィルタ（プラットフォーム/投稿種別/期間/BuzzScore）、ソート切り替え、検索結果一覧（無限スクロール/ページネーション） |
| SCR-015 | エラー/権限なし画面 | 404・500・権限エラー等の共通エラー表示。 | エラーメッセージ、ホームへ戻る導線 |

## 画面グルーピング（サイドナビゲーション構成）

ダッシュボードのサイドナビゲーションは要件通り以下の8項目で構成します。

1. ホーム（SCR-003）
2. トレンド（SCR-004）
3. 競合分析（SCR-005 / SCR-006）
4. 投稿分析（SCR-007 / SCR-008）
5. AIレポート（SCR-009 / SCR-010）
6. ランキング（SCR-011）
7. 保存済み分析（SCR-012）
8. 設定（SCR-013）

検索結果画面（SCR-014）はヘッダーのグローバル検索バーから遷移する横断的な画面です。
