## 2. 投稿URL分析フローの詳細遷移（状態遷移）

投稿URL分析はジョブが非同期で進行するため、状態遷移図で表現します。

```mermaid
stateDiagram-v2
    [*] --> URL入力中: SCR-007表示
    URL入力中 --> URLバリデーション中: 分析実行ボタン押下
    URLバリデーション中 --> エラー表示: 不正なURL/未対応プラットフォーム
    エラー表示 --> URL入力中: 再入力

    URLバリデーション中 --> データ取得中: バリデーションOK
    データ取得中 --> データ取得失敗: 公式API呼出失敗/投稿が非公開・削除済み
    データ取得失敗 --> URL入力中: 再試行

    データ取得中 --> AI分析中: 投稿データ取得・保存成功
    AI分析中 --> AI分析失敗: OpenAI API呼出失敗
    AI分析失敗 --> AI分析中: リトライ

    AI分析中 --> BuzzScore算出中: AI分析完了
    BuzzScore算出中 --> 改善案生成中: BuzzScore算出完了
    改善案生成中 --> 類似投稿検索中: 改善案生成完了
    類似投稿検索中 --> 分析結果表示: SCR-008へ遷移

    分析結果表示 --> 保存済み: 保存ボタン押下(SCR-012へ反映)
    分析結果表示 --> レポート生成中: レポート出力ボタン押下
    レポート生成中 --> レポート完了: SCR-010で生成完了
    レポート完了 --> [*]
    保存済み --> [*]
```
